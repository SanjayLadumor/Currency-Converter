# Currency Converter 💱

A simple and responsive Currency Converter web application that allows users to convert currencies in real time using live exchange rates. This project focuses on API integration, responsive UI design, and smooth user interaction.

---

## 🚀 Live Demo

Check out the repository here:
<br>
https://sanjayladumor.github.io/Currency-Converter/

---

## ✨ Features

- 💱 Real-time currency conversion
- 🌍 Multiple international currencies supported
- ⚡ Fast and responsive user interface
- 🔄 Instant exchange rate updates
- 📱 Fully responsive design
- 🎨 Clean and modern UI
- 🧩 Easy-to-use conversion interface

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/SanjayLadumor/Currency-Converter.git
```

Navigate to the project folder:

```bash
cd Currency-Converter
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 💡 Project Goal

The main goal of this project was to learn how to work with APIs and build practical real-world applications using frontend technologies. Currency converter projects are commonly used to practice API integration, state management, and responsive UI development while working with live financial data.
